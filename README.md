# Mis OR — V1

V1 sin Android Studio: aplicación web instalable (PWA).

Incluye las OR del Excel inicial, búsqueda, agrupación por Número de orden, alta de nuevas OR, importación de Excel sin borrar las existentes, alertas visuales desde 30 días, respaldo/restauración y notificaciones al abrir la app.

## Publicar en GitHub
1. Crear un repositorio nuevo.
2. Subir todos estos archivos.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Abrir la URL publicada.
5. En Android Chrome → menú ⋮ → Agregar a pantalla de inicio / Instalar aplicación.
6. Permitir notificaciones.

## Nota
La V1 comprueba las alertas cuando se abre/usa la app. Para una alarma garantizada aun con la app completamente cerrada, la V2 debe usar notificaciones nativas.
