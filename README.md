# Mis OR — V2

V2 de Mis OR, preparada para celular y como PWA instalable.

## Incluye
- Diseño adaptado a celulares.
- Botones grandes y formularios cómodos.
- Instalación como aplicación desde Chrome/Android cuando el navegador la ofrezca.
- Manifest PWA con iconos PNG de 192x192 y 512x512.
- Service Worker con caché y actualización de versión.
- Mantiene búsqueda, filtros, Nueva OR, Importar Excel, Respaldo, Restaurar y alertas.
- Las OR existentes no se borran al importar Excel o restaurar un respaldo.

## Publicar en GitHub Pages
Reemplazar los archivos de la V1 por los archivos de esta V2 en el repositorio, hacer Commit changes y esperar a que GitHub Pages publique.

## Instalar en Android
1. Abrir la URL publicada con Chrome.
2. Si aparece el botón "📲 Instalar", tocarlo.
3. También puede aparecer "Instalar aplicación" en el menú ⋮ de Chrome.
4. Aceptar la instalación.
5. El icono "Mis OR" quedará en la pantalla del teléfono.

## Importante
La notificación de +30 días se comprueba cuando se abre/usa la app. Esta V2 no promete una alarma en segundo plano con la app completamente cerrada.
